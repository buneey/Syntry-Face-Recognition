PROBLEMS:

❌ Ubuntu 22.04

glibc 2.35

EmguCV requires ≥ 2.38

Impossible without recompiling OpenCV

❌ AlmaLinux

Older glibc

Missing VTK / LAPACK ABI versions

Emgu runtime not built for RHEL ecosystem

❌ net8.0-windows

Forces Windows APIs

Breaks Linux runtime resolution
